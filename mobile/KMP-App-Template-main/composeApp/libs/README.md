# Local Libraries Directory

Place your local library files (.jar, .aar) here.

For Clerk SDK:
1. Download or build the Clerk KMP library
2. Place the .jar or .aar file in this directory
3. The build.gradle.kts is configured to automatically include all files from this directory

Example:
- clerk-kmp-0.1.9.jar
- any-other-library.aar
